# 🍽️ Zomato Data Analysis – Power BI | Tableau | SQL | Excel

## 📊 Objective
To analyze restaurant performance, customer ratings, and trends using Zomato’s dataset across cities and cuisines.

## ⚙️ Process
- Cleaned and prepared raw data in Excel.  
- Used SQL for data extraction, joins, and filtering of restaurant details and reviews.  
- Built Tableau dashboards to visualize top-performing cities and cuisines.  
- Designed a Power BI report to track restaurant ratings, orders, and customer engagement.

## 💡 Key Insights
- Identified cities with the highest restaurant density and average ratings.  
- Found correlations between price range, cuisine type, and customer satisfaction.  
- Visualized which cuisines drive higher ratings and customer retention.

## 🧰 Tools Used
Power BI | Tableau | SQL | Excel
